## Capture checklist

- Use the same browser zoom and a readable resolution.
- Make the page title and relevant UI visible, but avoid showing browser bookmarks or unrelated desktop content.
- Do not include passwords, database error pages, OTPs, mail credentials, API keys, or full personal data.
- For Figure 15, use the proposed architecture from the final report and write “Proposed AWS Public Cloud Architecture” directly in the diagram.
- Number figures exactly as used in the final document and give every image a short caption.
